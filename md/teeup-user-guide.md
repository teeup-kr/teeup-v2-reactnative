# 티업링크 사용설명서

골프 동호회 운영을 앱 하나로. 클럽 개설부터 라운딩 모집, 스코어 기록, 회비 정산까지.

---

## 1. 시작하기

### 설치

- **iPhone** — App Store에서 `티업링크` 검색
- **Android** — Play 스토어에서 `티업링크` 검색

### 로그인

앱을 켜면 로그인 화면이 나옵니다. 두 가지 중 편한 쪽을 쓰세요.

- **Google로 로그인**
- **Apple로 로그인** (iPhone)

따로 아이디·비밀번호를 만들 필요가 없고, 처음 로그인하는 순간 계정이 만들어집니다.

### 약관 동의와 프로필 작성

첫 로그인이면 약관에 동의한 뒤 프로필을 작성합니다.

| 항목 | 필수 여부 |
| --- | --- |
| 이름, 닉네임 | 필수 |
| 연락처 | 필수 |
| 생년월일, 성별 | **선택** |
| 평균타수, 핸디캡 | 선택 (나중에 입력 가능) |

> 생년월일과 성별은 안 넣어도 모든 기능을 쓸 수 있습니다. 입력하면 팀 편성에서 연령대를 고려하거나 티박스를 추천하는 데 쓰입니다.

## 2. 화면 둘러보기

화면 맨 아래에 다섯 개의 탭이 있습니다.

| 탭 | 하는 일 |
| --- | --- |
| **전체** | 모든 메뉴를 펼쳐 봅니다 |
| **홈** | 다음 라운딩, 최근 기록, 바로가기 |
| **클럽** | 내 클럽 목록, 클럽 찾기 |
| **모임** | 라운딩·소셜 모임 목록 |
| **마이** | 내 정보, 내 모임, 기록, 알림 |

탭바 바로 위의 **티업링크 사용설명서** 띠를 누르면 이 문서가 열립니다.

## 3. 클럽

### 클럽 가입하기

1. **클럽** 탭 → 클럽 목록
2. 지역(시/도 → 시/군/구)이나 이름으로 검색
3. 마음에 드는 클럽을 눌러 소개·회비·활동 지역 확인
4. **가입 신청**

신청하면 **승인 대기** 상태가 되고, 클럽 리더나 매니저가 승인하면 멤버가 됩니다.

### 클럽 만들기

**전체** 메뉴 → **클럽 만들기** (또는 클럽 탭에서 클럽 만들기)

| 입력 항목 | 설명 |
| --- | --- |
| 클럽명 | 예) 주말 골프 모임 |
| 모임 유형 | 정기 모임 / 비정기 모임 |
| 활동 지역 | 시/도 + 시/군/구 (여러 개 선택 가능) |
| 정원 | 예) 20 |
| 클럽 소개 | 어떤 모임인지, 어떤 분을 환영하는지 |
| 회비 | 금액과 납부 안내 (선택) |

만들면 본인이 자동으로 **리더**가 됩니다.

### 클럽 상세 화면

| 메뉴 | 내용 |
| --- | --- |
| **클럽 소개** | 소개글, 활동 지역, 대표자, 개설일 |
| **공지사항** | 운영진이 올린 공지 |
| **클럽 규정** | 회칙, 라운딩 규칙 등 |
| **회비** | 금액, 납부 주기 |
| **멤버** | 멤버 목록과 각자의 기록 |
| **라운딩 기록** | 클럽의 지난 라운딩 결과 |

### 멤버 등급

| 등급 | 권한 |
| --- | --- |
| **리더** | 모든 권한. 클럽 정보 수정, 멤버 승인·등급 변경 |
| **매니저** | 모임 개설, 공지·규정 작성, 가입 승인 |
| **일반멤버** | 모임 참가, 기록 확인 |

### 클럽 관리 (리더·매니저)

클럽 상세 → **클럽 관리**

- **멤버 관리** — 가입 신청 승인·반려, 멤버 메모
- **공지사항** — 작성·수정·삭제
- **클럽 규정** — 카테고리별로 규정 정리
- **회비 관리** — 금액과 주기(월 1회 / 분기 1회 / 연 1회 / 일회성) 설정
- **모임 설정** — 모임 기본값
- **통계** — 클럽 활동 통계
- **멤버 권한 관리** — 매니저 지정

## 4. 모임

모임은 두 종류입니다.

- **라운딩 모임** — 실제 골프 라운딩
- **소셜 모임** — 식사, 뒤풀이, 스크린골프 등

### 라운딩 모임 만들기 (리더·매니저)

**전체** 메뉴 → **라운딩 모임 만들기**

| 입력 항목 | 예시 |
| --- | --- |
| 모임명 | 봄맞이 라운딩 |
| 모임 시간 | 날짜/시간 선택 |
| 신청 마감 | 참가 신청을 닫을 시각 |
| 골프장 | 한강 CC |
| 지역 | 서울 강동구 |
| 예약자명 | 예약을 건 사람 |
| 정원 | 16 |
| 비용 | 그린피 / 카트비 / 캐디피 등 |
| 모임 소개 | 초보 환영, 라운딩 후 식사 등 |

### 소셜 모임 만들기

**전체** 메뉴 → **소셜 모임 만들기**. 모임명·시간·장소·참가자 수만 넣으면 됩니다. 참가 대상을 **모든 클럽 멤버**로 둘지 따로 고를지 정할 수 있습니다.

### 참가 신청

1. **모임** 탭에서 모임을 고릅니다
2. 상세 화면 아래 **참가 신청**
3. 마음이 바뀌면 **참가신청 취소**

신청 마감 시각이 지나거나 운영진이 **신청 마감하기** 를 누르면 더 이상 신청할 수 없습니다.

### 게스트 추가

클럽 멤버가 아닌 지인을 데려갈 때는 운영진이 모임에 **게스트** 로 추가할 수 있습니다. 이름만 넣으면 되고, 정산에도 함께 잡힙니다.

### 팀 편성

라운딩 전에 운영진이 조를 짭니다.

1. 모임 상세 → **팀 편성**
2. **새 팀 추가** 로 조를 만들고
3. **미할당 참가자 추가** 로 각 조에 배정

### 모임 진행

| 단계 | 누가 | 무엇을 |
| --- | --- | --- |
| 신청 마감 | 운영진 | 참가자 확정 |
| 팀 편성 | 운영진 | 조 편성 |
| 라운딩 시작 | 운영진 | 진행 상태로 전환 |
| 점수 입력 | 참가자·운영진 | 스코어 기록 |
| 라운딩 종료 | 운영진 | 기록 확정 |
| 정산 | 운영진 | 비용 분배 |

## 5. 스코어 기록

### 모임에서 입력하기

모임 상세 → **점수 입력** → 참가자별 스코어 입력

### 혼자 기록하기

**홈** → **라운드 기록하기** 에서 모임과 상관없이 개인 기록을 남길 수 있습니다.

### 기록 확인

- **마이** → **기록** — 내 라운딩 기록, 평균타수, 핸디캡
- 모임 상세 → **점수 통계** — 총 스트로크, 최고 홀, 최악 홀
- 클럽 상세 → **라운딩 기록** — 클럽 전체 기록

## 6. 정산

라운딩이 끝나면 비용을 나눕니다.

1. 모임 상세 → **정산/경비**
2. 항목별로 금액 입력 (그린피, 카트비, 식비 등)
3. 항목마다 **누가 부담할지** 고릅니다 — 전원이면 1/N, 일부만이면 그 사람들끼리
4. 1인당 금액이 자동 계산됩니다
5. 다 받으면 **정산 완료 처리**

> 티업링크는 금액을 계산하고 기록만 합니다. 실제 송금은 앱 밖에서 하세요. 앱 안에서 결제되는 것은 없습니다.

## 7. 회비

클럽 회비는 리더·매니저가 **클럽 관리 → 회비 관리** 에서 등록합니다.

- 금액과 주기(월 1회 / 분기 1회 / 연 1회 / 일회성)
- 사용처나 납부 계좌 안내

멤버는 클럽 상세의 **회비** 에서 확인합니다.

## 9. 안전하게 쓰기 — 신고와 차단

### 신고

클럽·모임·공지·규정 화면, 그리고 멤버 목록의 각 줄에 **⋯** 버튼이 있습니다.

**⋯ → 신고하기** → 사유 선택 (스팸·광고 / 욕설·비방·괴롭힘 / 부적절한 콘텐츠 / 사기·허위 정보 / 개인정보 노출 / 기타) → 필요하면 설명을 적고 제출

접수된 신고는 운영진이 **24시간 이내**에 확인하고 조치합니다.

### 차단

**⋯ → 사용자 차단**

차단하면 그 사람이 만든 클럽·모임·공지와 참가자 목록이 더 이상 보이지 않습니다.

해제는 **마이 → 회원정보 수정 → 차단 관리** 에서 언제든 가능합니다.

### 부적절한 표현 차단

클럽명, 모임명, 공지, 규정, 닉네임에 욕설이나 광고성 문구가 들어가면 등록되지 않습니다.

## 11. 자주 묻는 질문

**클럽에 가입하지 않아도 쓸 수 있나요?**
클럽 목록을 둘러보고 개인 라운딩 기록을 남기는 것은 가능합니다. 모임 참가나 정산은 클럽에 속해야 합니다.

**클럽을 여러 개 가입할 수 있나요?**
네, 제한이 없습니다.

**가입 신청을 했는데 아무 일도 안 일어납니다.**
클럽 리더나 매니저가 승인해야 멤버가 됩니다. 승인되면 알림이 갑니다.

**모임을 만들 수 없습니다.**
모임 개설은 리더와 매니저만 가능합니다. 리더에게 매니저 권한을 요청하세요.

**앱에서 돈이 오가나요?**
아니요. 정산 기능은 금액을 계산하고 기록할 뿐입니다. 실제 송금은 앱 밖에서 합니다.

**생년월일과 성별을 꼭 넣어야 하나요?**
아니요. 선택 항목입니다. 넣으면 팀 편성과 티박스 추천에 쓰입니다.

**차단한 사람을 다시 보려면?**
마이 → 회원정보 수정 → 차단 관리 → 차단 해제
