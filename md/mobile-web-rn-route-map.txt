mobile-web -> RN route/layout mapping

Global layout (mobile-web)
- Header (logo/auth/links)
- Main (Routes)
- Footer
- BottomNavigation (전체/홈/클럽/모임/마이)
- FullMenu overlay (auth-gated items)

RN target (expo-router)
- Root layout should render Header + Slot + Footer + BottomNavigation + FullMenu
- (tabs) group should be plain Slot (no Tabs navigator)

Route mapping
- /                      -> app/(tabs)/index.js
- /login                 -> app/login.js
- /register              -> app/register.js
- /register-success      -> app/register-success.js
- /auth/forgot-password  -> app/forgot-password.js
- /auth/reset-password   -> app/reset-password.js
- /terms                 -> app/terms.js (redirects to /auth/terms)
- /auth/terms            -> app/auth/terms.js
